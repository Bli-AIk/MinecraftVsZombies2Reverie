# Minecraft Vs Zombies 2: Reverie

| English | [简体中文](Readme-ZH.md) |
|:---------------:|:----:|

**Minecraft Vs Zombies 2: Reverie** is an **unofficial**, **highly experimental**, **community** branch of **MVZ2**.

The purpose of this branch is to create a brand new, reimagined main story line without directly modifying the original content of MVZ2 as much as possible, featuring:
* **Level progression from the official Touhou Project series (integer-numbered titles, mainline games)**
* **Roguelite gameplay** using **card draws** to configure your deck instead of card selection
* Long level progression design inspired in part by the **"Foodstuff Vs Mice" online game**

At the same time, this branch will also:
* Introduce a large number of new contraptions and enemies:
    * **Original designs**
    * **References, tributes, or adaptations of other works**
    * **Fan creations, memes, and inside jokes within reasonable limits**
* A possible series of **QoL enhancements**

We respect all copyrights of the original MVZ2. Based on MVZ2 being open-sourced under GPLV3, this branch is also open-sourced under GPLv3 and is completely open-source community oriented.

Anyone can submit Issues, PRs, start discussions, and provide suggestions, opinions, and ideas for the development of this branch.

View the original MVZ2 project [readme](original_readme.md) here.

### Guidelines for Using Designs and Assets from Other Works

This branch may reference designs and assets from other works (such as some Minecraft Mods). To ensure that we do not infringe on the copyrights of others, we hereby declare:

* If designs or assets from other works are used in the project, **the source must be clearly indicated**.
* **It is prohibited** to reference closed-source assets, or assets that are used without permission or in violation of the original license.
* If your assets are used in this project (MVZ2R), but you **do not want them to be used**, you can submit a removal request with conclusive evidence, and we will delete or replace them.

#### Scope of Source Attribution

When referencing the designs/assets of others, please provide the following information as completely as possible:

* **Original Name** (The official name of the work/asset)
* **Common Translation** (For your language, optional)
* **Author or Author Team Name**
* **Original Link(s)** (e.g., GitHub / Modrinth / CurseForge / Official Website, list as many as you can)
* **License** (If you are referencing assets, please also list the license for the **resource files**)
