# MC大战僵尸2：幻想曲

| [English](Readme.md) | 简体中文 |
|:---------------:|:----:|

**MC大战僵尸2：幻想曲** 是**MVZ2**的一个**非官方**的、**极度实验性**的**社区**分支。

该分支的目的是尽量在不直接修改 MVZ2 原作内容的基础上，制作一条全新的、重新构想的主线流程，其特点包括：
* **东方 Project 系列正作（整数作，正传）的关卡流程**
* 代替选卡而使用**抽卡**配置卡组的 **Rougelite 玩法**
* 灵感部分源自 **《美食大战老鼠》网游** 的 长关卡流程设计

同时，本分支还将：
* 引入大量全新的器械与敌人：
    * **原创设计**
    * **对其他作品的引用、致敬或改编**
    * **在合理限度内的二次创作、捏他与整活玩梗**
* 可能的一系列 **QoL 增强**

我们尊重 MVZ2 原作的一切著作权，在 MVZ2 基于 GPLV3 开源的基础上，这个分支同样以 GPLv3 开源，并完全面向开源社区。

任何人可以提交 Issue，PR，展开讨论，对该分支的发展提出建议意见想法。

在这里查看 MVZ2 原项目 [readme](original_readme-ZH.md)。

### 其他作品设计与素材使用说明

本分支可能会引用来自其他作品的设计与素材（例如部分 Minecraft Mod）。为确保不侵犯他人版权，特此声明：

* 项目中若使用其他作品的设计或素材，**必须显著标明出处**。
* **禁止**引用闭源的，或未经许可、违反原始许可证的素材。
* 如果您的素材被用于本项目（MVZ2R），但您**不希望其被使用**，可在提供确凿证据的情况下，提出撤销申请，我们将予以删除或替换。

#### 出处标注的范围

引用他人设计/素材时，请尽可能完整地提供以下信息：

* **原名称**（作品/素材的官方名称）
* **常见译名**（针对您的语言，可选）
* **作者或作者团队名称**
* **原始链接**（如 GitHub / Modrinth / CurseForge / 官方网站等，有多少列多少）
* **许可证**（如果您引用的是素材，请一齐列出**资源文件**的许可证）

示例：

> *原名称*：Create<br>
> *常见译名*：机械动力<br>
> *作者团队*：Create Team<br>
> *原链接*：[GitHub](https://github.com/Creators-of-Create/Create) / [Modrinth](https://modrinth.com/mod/create) / [CurseForge](https://www.curseforge.com/minecraft/mc-mods/create)<br>
> *许可证*：Assets License (All Rights Reserved) / Code License (MIT)
