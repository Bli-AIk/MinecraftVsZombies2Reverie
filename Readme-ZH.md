# MC大战僵尸2：幻想曲

| [English](Readme.md) | 简体中文 |
|:---------------:|:----:|

**MC大战僵尸2：幻想曲** 是MVZ2的一个非官方实验性分支。该分支的目的是尽量在不直接修改MVZ2原作内容的基础上，制作一条灵感源自rougelite玩法、《美食大战老鼠》网游、且关卡流程尽可能贴近东方Project系列正作（整数作，正传）的reimagin主线，同时带来一系列的QoL增强。

我们尊重MVZ2原作的一切著作权，在MVZ2基于GPLV3开源的基础上，这个分支同样以GPLv3开源，并完全面向开源社区。任何人可以提交Issue，PR，展开讨论，对该分支的发展提出建议意见想法。

在这里查看原项目 [readme](original_readme-ZH.md)。
